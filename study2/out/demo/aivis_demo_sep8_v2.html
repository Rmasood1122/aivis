03Why an unmeasured extractor cannot be trusted — demonstrated on this data

During this study's own run, a naive text match was tried first. It is the kind of matching most tools in this category ship.

34/89 naive match "credible" A substring match hands the brand a 38% mention rate. Every hit was the English adjective — "credible sources," "credible agency," "credible proof." Zero were the firm.
0/89 phrase-matched, read in context The corrected figure. The stored transcripts made the check possible — the raw text was read, not just counted. A second near-collision ("Credibility," 6/89) was caught the same way.

This is why every count in this document is labelled unvalidated parse until an agreement coefficient (Cohen's κ) is published against a hand-labelled set — with the labelled set itself made public, so the grade can be re-marked by anyone. No vendor in this category publishes that number. Until it exists here, it is not claimed here either.

05Check this yourself

Every response in this study is stored raw, with its request payload and a SHA-256 hash, at the moment of collection. The whole file folds into one digest. Change any byte of any response afterward and the digest breaks. Tamper-evident, hash-verified — nothing stronger is claimed.

The checker is a single Python file using only the standard library — no install of anything from this project, no network. It recomputes every row hash from the stored text and the bundle digest from the rows, and compares against the figures printed above. It has been run in a clean container by a third party.

python verify_evidence.py pr_agency_run4.jsonl --expect 9eb756a2… > MATCH 191 of 191 clean rows · VERDICT PASS

Printed limitation, verbatim from the checker itself: a pass means the file was not edited after it was written. It does not prove the responses came from the engine named in the payload, or that the run happened as described — a hash cannot establish either. Printing that limit is the point: a measurement whose boundaries are stated is one that can be trusted inside them.

06What is not claimed

No accuracy figure
Unlocked by a published κ against a public labelled set. In progress; not claimed before it exists.
No ranking
Unlocked by an order-flip test showing position is stable under prompt reordering. Until then: presence and position counts only.
No revenue link
Zero published evidence connects AI recommendation rates to consultations, in any vertical. Measuring whether that link exists is the study proposed below — it is not assumed at signing.
Abstention over estimation
A metric below its power floor prints ABSTAIN, not a point estimate. Below-power silence is a feature of the instrument, not a gap in it.

07The study this makes possible

An agency that places clients in media controls an intervention with a known date. That is a natural experiment sitting unused across an entire book of business, and nobody in this category has run it: measure the AI recommendation rate before a placement, re-measure at 30, 60 and 90 days, control against untreated competitors in the same market.

Outcomes are pre-committed in writing before the first measurement. If placements move AI answers: a jointly written case study, agency named. If they don't at the stated minimum detectable change: the agency learns first, with reweighting guidance in the deliverable. Either way the number is real — and either way it is a number no competitor of the agency has.

Founding engagements (first three): $2,500 per quarter per market, in exchange for named case-study rights. List thereafter: $5,000. Full charter, including the power floor, confounding controls, and the intake attribution kit, is a two-page read.
